Changing of website: 
(For setup see: https://quarto.org/docs/publishing/github-pages.html; I use publishing via the publish command, which necessitates a „gh-pages“ directory.) 

Open your repository.
Make changes to your index.qmd or other .qmd files.

Rendert the changes, so that new html files are created in the .doc folder
-	quarto render

Making changes to GitHub repository.
git add .
git commit -m "Updated website content"
git push

Now publish:
-	quarto publish
